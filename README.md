# go-bench-pprof-action

## 一个便捷的go bench 并分析工具

## 需求

go自带的bench工具很好用,但是当我们需要具体的分析某个函数的具体性能瓶颈时,需要配合pprof工具进行分析
每次需要写很多命令进行pprof采集,分析,可视化等操作,比较麻烦,但同时也是一个高频操作

因此我希望有一个工具能够自动化这个过程,让我们能够更方便的进行性能分析

## 输入

```
top: 10 # pprof排序输出前K个
match: 正则表达式 # 只分析函数名匹配正则表达式的函数
mem: bool # 是否分析内存
exclude: # 排除的路径
```

## 输出
默认以文本输出到`GITHUB_STEP_SUMMARY`,后期可以增加输出为`json`,`html`等格式的功能
